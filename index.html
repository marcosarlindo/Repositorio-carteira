Como isso funciona / avisos

Posições: este arquivo não se conecta à sua conta na XP — a XP não oferece isso para pessoa física. Os tickers, quantidades e preço médio abaixo foram tirados do print que você me enviou; edite os campos de Qtd. e Preço médio diretamente na tabela sempre que comprar/vender, ou apague/adicione ativos. Tudo fica salvo neste navegador (não é enviado a lugar nenhum).

Cotações: os preços atuais vêm da API pública gratuita brapi.dev. PETR4, VALE3, ITUB4 e MGLU3 funcionam sem cadastro; qualquer outro ticker (BBSE3, AXIA3, BBAS3, SAPR11, etc.) exige um token gratuito — crie uma conta em brapi.dev/dashboard e cole o token no campo acima. O plano grátis só aceita 1 ativo por requisição, então o dashboard busca cada ativo separadamente (por isso o intervalo padrão é 5 min, não instantâneo — sem problema, já que não é preciso tempo real).

Privacidade do token: como é um arquivo local que só você abre, é seguro colar seu token aqui — mas não compartilhe este arquivo com mais ninguém depois de colar o token, porque ele fica visível no código da página.

Abra fora do chat: baixe o arquivo e abra num navegador normal (Chrome, etc.) — dentro de uma pré-visualização em iframe as cotações ao vivo podem não carregar.

Se a atualização der erro persistente, pode ser bloqueio de CORS do provedor — nesse caso me avise para eu trocar de fonte de dados.
